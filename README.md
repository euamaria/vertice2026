# vertice2026
O vértice central - sustentando a tese de "comandante máximo" ou "ponto de convergência" de múltiplos esquemas.

## Sobre o projeto
Este é um trabalho em progresso e está aberto para que qualquer pessoa possa corrigir e complementar as fontes.

A ideia destes infográficos é fazer uma releitura do famoso PowerPoint da força-tarefa da Lava Jato de forma adaptada para a nossa realidade (os procuradores da Lava Jato de 10 anos atrás). Diferentemente deles, a gente pode dizer: **"Aqui a gente tem provas E convicção"**.
